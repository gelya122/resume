# Интерактивное резюме

Одностраничный сайт-резюме с фильтрацией навыков по категориям, поиском и переключением светлой/тёмной темы с сохранением выбора после перезагрузки страницы.

## Ссылки

- Опубликованный сайт: https://gelya122.github.io/resume/
- Репозиторий: https://github.com/gelya122/resume

## Стек технологий

- HTML5
- CSS3 (Flexbox, CSS Grid, CSS-переменные)
- JavaScript (без библиотек и фреймворков)
- Google Fonts (IBM Plex Sans)

## Выполненные требования

- Семантичная HTML-структура: `header`, `nav`, `main`, `section`,
  `article`, `figure`, `time`
- Адаптивная вёрстка: корректно отображается на 1440 / 768 / 375 px
- Отсутствует горизонтальная прокрутка на мобилке
- Разделы: обо мне, образование, опыт работы, проекты, навыки, контакты
- Фильтрация навыков по категориям (Frontend / Backend / Tools / AI-assisted)
- Поиск навыков без учёта регистра
- Совместная работа поиска и фильтра категорий
- Сообщение «Ничего не найдено» при отсутствии результатов
- Светлая и тёмная тема с сохранением выбора в `localStorage`
- Все интерактивные изменения происходят без перезагрузки страницы

## Не выполненные требования

- Нет

## Дизайн-референс

- Собственный дизайн без использования готовых шаблонов.
  В качестве источника идей использовались публичные примеры резюме и сайтов-визиток (Pinterest / Behance).
