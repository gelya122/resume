Проекты

Бот для выдачи лид-магнитов

Сервис для выдачи полезных материалов подписчикам канала через интерактивные кнопки в постах.
При нажатии кнопки пользователем открывалась mini app, которая проверяла наличие подписки на канал. Если пользователь ещё не был подписан, ему показывалось соответствующее сообщение с предложением подписаться. После успешной проверки пользователь переходил в бота для получения материала.

Платформа для создания и публикации сайтов

Веб-конструктор, позволяющий создавать многостраничные сайты без непосредственного написания кода.
Пользователь мог создавать сайты и страницы, добавлять базовые элементы — текст, изображения, кнопки, фигуры и анимации — и размещать их. Для страниц можно было настраивать шапку и подвал, подключать собственные и Google Fonts, добавлять код в head, подключать Яндекс Метрику и другие настройки.
Платформа также поддерживала подключение собственных доменов, выпуск HTTPS-сертификатов и публикацию сайтов. Без собственного домена опубликованные страницы были доступны через адрес конструктора.

Система аналитики источников подписчиков

Сервис позволял определять, с какой рекламной интеграции пользователь пришёл в канал мессенджера, и отслеживать дальнейшую историю его подписки.
Когда пользователь переходил с лендинга в приложение мессенджера, mini app фиксировала источник перехода и связывала его с идентификатором пользователя. После подписки система могла определить, откуда пришёл подписчик, а при последующей отписке — сохранить и эту информацию.

Веб-клиент мониторинга судов

Веб-интерфейс для отображения информации о судах на интерактивной карте.
Данные поступали с сервера в JSON-формате и содержали координаты, тип судна и другие характеристики. Пользователь мог изменять масштаб карты, фильтровать отображаемые суда по типу и выбирать отдельное судно для просмотра его маршрута.
Для работы в условиях отсутствия подключения использовалась полноценная offline-карта на основе заранее подготовленных картографических тайлов.
Я занималась внешним видом и клиентской частью приложения: отображением объектов на карте, интерфейсом взаимодействия с картой и представлением полученных данных.
Моя роль: frontend / веб-клиент.

Онлайн-платформа для автоматизации деятельности онлайн-школы

Учебный проект, представляющий собой единую систему для управления онлайн-школой.
Платформа состояла из нескольких частей:
Сайт для студентов: регистрация и авторизация; каталог курсов; просмотр курсов и уроков; отслеживание прогресса; выполнение домашних заданий; просмотр уведомлений; личный кабинет.
Настольное приложение для сотрудников: управление студентами; управление курсами и потоками; работа с домашними заданиями; проверка работ; управление преподавателями и менеджерами; составление расписания открытия занятий; просмотр успеваемости и статистики; отправка уведомлений.
Все части системы взаимодействовали с единой базой данных через API на ASP.NET Core.
Проект был разработан самостоятельно как дипломный прототип.
